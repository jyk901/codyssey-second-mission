# 실행 화면 로그

`python main.py` 를 실제로 실행한 화면입니다. (입력한 값이 프롬프트 뒤에 함께 표시됩니다.)

## 1. 첫 실행 → 메뉴 → 종료

```text
📂 저장된 데이터를 불러왔습니다. (퀴즈 6개, 최고점수 0점)
========================================
        🎯 나만의 퀴즈 게임 🎯
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 종료
========================================
선택: 6
👋 퀴즈 게임을 종료합니다.

```
