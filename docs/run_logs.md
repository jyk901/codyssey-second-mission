# 실행 화면 로그

`python main.py` 를 실제로 실행한 화면입니다. (입력한 값이 프롬프트 뒤에 함께 표시됩니다.)

## 1. 첫 실행 → 메뉴 → 종료

```text
🆕 저장된 데이터가 없어 기본 퀴즈로 시작합니다.
========================================
        🎯 나만의 퀴즈 게임 🎯
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택: 5
👋 퀴즈 게임을 종료합니다.

```
