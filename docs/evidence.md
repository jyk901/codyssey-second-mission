## 3. 퀴즈 풀기 (문제 수 선택, 힌트, 결과)

```text
📂 저장된 데이터를 불러왔습니다. (퀴즈 6개, 최고점수 0점)
[메뉴 출력: 1.풀기 2.추가 3.목록 4.점수 5.삭제 6.종료]
선택: 1
풀 문제 수 (1-6): 2

📝 퀴즈를 시작합니다! (총 2문제)

----------------------------------------
[문제 1]
임진왜란 때 한산도 대첩을 이끈 장군은?

1. 권율
2. 김시민
3. 이순신
4. 곽재우

정답 입력 (힌트: h): h
💡 힌트: 거북선을 만든 것으로 유명한 수군 장수  (문제 배점의 절반이 차감됩니다)
정답 입력 (힌트: h): 3
✅ 정답입니다!

----------------------------------------
[문제 2]
광복절은 몇 월 며칠일까?

1. 3월 1일
2. 6월 25일
3. 8월 15일
4. 10월 3일

정답 입력 (힌트: h): 3
✅ 정답입니다!

========================================
🏆 결과: 2문제 중 2문제 정답! (75점)
💡 힌트 1회 사용으로 점수가 차감되었습니다.
🎉 새로운 최고 점수입니다!
========================================

[메뉴 출력: 1.풀기 2.추가 3.목록 4.점수 5.삭제 6.종료]
선택: 6
👋 퀴즈 게임을 종료합니다.
```

## 4. 퀴즈 추가 / 목록

```text

[메뉴 출력: 1.풀기 2.추가 3.목록 4.점수 5.삭제 6.종료]
선택: 2

📌 새로운 퀴즈를 추가합니다.

문제를 입력하세요: 영화 '기생충'의 감독은?
선택지 1: 박찬욱
선택지 2: 봉준호
선택지 3: 김기덕
선택지 4: 이창동
정답 번호 (1-4): 2
힌트 (없으면 Enter): 

✅ 퀴즈가 추가되었습니다!

[메뉴 출력: 1.풀기 2.추가 3.목록 4.점수 5.삭제 6.종료]
선택: 3

📋 등록된 퀴즈 목록 (총 7개)

----------------------------------------
[1] 훈민정음(한글)을 창제한 조선의 왕은?
[2] 임진왜란 때 한산도 대첩을 이끈 장군은?
[3] 3·1 운동이 일어난 해는?
[4] 남한에서 가장 높은 산은?
[5] 광복절은 몇 월 며칠일까?
[6] 팔만대장경이 보관되어 있는 사찰은?
[7] 영화 '기생충'의 감독은?
----------------------------------------

[메뉴 출력: 1.풀기 2.추가 3.목록 4.점수 5.삭제 6.종료]
선택: 6
👋 퀴즈 게임을 종료합니다.
```
